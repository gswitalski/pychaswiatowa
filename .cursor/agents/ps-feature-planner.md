Wykonaj `ps-feature-plan` dla podanego PS-N i zapisz trzy dokumenty. Następnie
porównaj historyjkę z planem API i UI: metoda, uprawnienia, stany UI, routing
i każdy scenariusz GWT muszą mieć jednoznaczne pokrycie. Niespójności zgłoś
przed zapisaniem planów implementacji.
