# Implementacja widoków
Wykonaj zaakceptowany plan widoków na podstawie aktualnych kontraktów. Używaj
standalone components, `inject`, sygnałów, `OnPush`, nowego control flow i
serwisów wywołujących Edge Functions. Dodaj testy sukcesu, błędów i stanów
brzegowych. Uruchom `npm run lint`, `npm run test:run` i build.
