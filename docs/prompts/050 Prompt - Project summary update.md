Poniżej znajdują się trzy dokumenty dotyczące tego samego projektu:

Podsumowanie projektu – dokument opisujący ogólny zarys, cele i zakres projektu
Plan implementacji API – szczegółowy plan wdrożenia warstwy backendowej/API
Plan implementacji widoków – szczegółowy plan wdrożenia warstwy frontendowej/UI

Etap opisany w planach implementacji API oraz widoków został już zrealizowany. Twoim zadaniem jest zaktualizowanie dokumentu podsumowującego projekt tak, aby odzwierciedlał aktualny stan prac.

Zadanie

Wykonaj poniższe kroki:

Przeanalizuj treść wszystkich trzech dokumentów – zrozum cel projektu, zakres oraz szczegóły techniczne obu planów implementacji.
Zidentyfikuj różnice między aktualną treścią podsumowania a tym, co faktycznie zostało zaimplementowane zgodnie z planami API i widoków (np. nowe funkcjonalności, komponenty, endpointy, zmiany architektoniczne).
Zaktualizuj dokument podsumowania projektu, uwzględniając zrealizowane elementy z obu planów implementacji – tak, aby dokument odzwierciedlał rzeczywisty, aktualny stan projektu.
Zachowaj charakter dokumentu – podsumowanie ma pozostać:
zwięzłe i syntetyczne (nie rozbudowuj go w szczegółowy opis techniczny),
napisane w tym samym stylu i tonie co oryginał,
skoncentrowane na kluczowych informacjach, a nie na drobnych detalach implementacyjnych.
Nie kopiuj całych fragmentów planów implementacji – wyciągnij z nich jedynie informacje istotne z punktu widzenia ogólnego podsumowania projektu (np. co zostało zrealizowane, jakie kluczowe decyzje techniczne podjęto, jaki jest aktualny status).
Wymagania dotyczące wyniku
Zaktualizowany dokument powinien zachować oryginalną strukturę (nagłówki, sekcje) podsumowania projektu, chyba że zmiany merytoryczne wymagają dodania/usunięcia sekcji.
Jeśli w oryginalnym podsumowaniu istniała sekcja dot. statusu/postępu prac – zaktualizuj ją, wskazując, że implementacja API i widoków została zakończona.
Unikaj dublowania informacji, które nie zmieniły się względem oryginału.
Jeśli natrafisz na sprzeczności między dokumentami (np. plan przewidywał coś innego niż finalnie opisano), zaznacz to krótko w podsumowaniu lub wybierz wersję bardziej aktualną/spójną z pozostałymi dokumentami.
Format wyjściowy

Zwróć wynik w formacie:

# Podsumowanie projektu (zaktualizowane)

[Tutaj pełna, zaktualizowana treść dokumentu podsumowującego]

Na końcu, poza głównym dokumentem, dodaj krótką sekcję:

## Lista wprowadzonych zmian
- [zmiana 1]
- [zmiana 2]
- ...

opisującą, co dokładnie zostało zaktualizowane względem oryginalnego podsumowania.
